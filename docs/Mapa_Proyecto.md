# Mapa del Proyecto: Bitácora Médica

Bienvenido al mapa principal del proyecto. Desde aquí puedes navegar a los diferentes componentes clave de la aplicación.
Esta estructura está diseñada para facilitar la comprensión del sistema y su mantenimiento, interconectando todas las partes para una visualización óptima en el grafo de Obsidian.

## Componentes Principales

- [[Frontend]]: Interfaz de usuario interactiva del proyecto.
- [[Backend]]: Servidor de lógica y procesamiento de API.
- [[Database]]: Persistencia de datos, modelos y esquemas.
- [[Pase_a_Produccion]]: Scripts y procedimientos para despliegue y puesta en marcha.

## Flujo General
El [[Frontend]] realiza peticiones al [[Backend]], el cual a su vez consulta la [[Database]] para leer o escribir información. Una vez completado el desarrollo local, se utilizan las herramientas descritas en [[Pase_a_Produccion]] para desplegar la solución en el servidor o entorno real.
