# Frontend

El Frontend del proyecto es responsable de la interfaz gráfica y la interacción fluida con el usuario.

## Tecnologías Principales
- React
- Vite (Empaquetador y entorno de desarrollo)
- Node.js (Gestión de dependencias)

## Estructura de Directorios
- Contiene los archivos fuente en la carpeta `src/`.
- Configuraciones de compilación en `vite.config.js`.
- Gestión de dependencias a través de `package.json` y `node_modules/`.

## Relaciones en el Proyecto
- Actúa como cliente principal consumiendo la API provista por el [[Backend]].
- Sus entregables (build) y empaquetado final son gestionados mediante los scripts documentados en la fase de [[Pase_a_Produccion]].
